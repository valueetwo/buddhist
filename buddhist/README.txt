BUDDHIST DASHBOARD

Folder project baru yang terpisah dari project PNG.

Struktur:
- index.html
- config.js
- data.js
- css/style.css
- js/app.js
- assets/
- audio/

Supabase:
Project memakai Supabase yang sama, tetapi data Buddhist dipisah ke tabel:
- buddhist_videos
- buddhist_materials
- buddhist_faq
- buddhist_sop

Desain:
- Tema cream / orange / gold
- Logo Buddhist dengan Dewi Kwan Im
- Dewa Bumi di sidebar
- Hero bacaan mantra
- Informasi bacaan kanan
- Cover/card mantra
- Favorit, playlist, riwayat
- Login admin Supabase
- Admin dapat tambah/edit mantra pada tabel buddhist_videos

Untuk GitHub Pages:
Upload seluruh isi folder "buddhist" ke repository baru atau ke folder /buddhist pada repository yang diinginkan.
